# 资源文档编辑器基础版本

应用窗口和嵌入组件均采用单视口 Live 编辑，可切换源码。不提供分屏模式。CSV 已接入 Live 单视口：独立段落的 `![描述](表格.csv)` 异步加载后显示只读表格摘要，光标移入时编辑引用源码，离开后恢复展示；引用编辑保留表格占用高度并按顶部内容保持滚动位置，避免页面上移。PDF 同样接入 Live，支持单页预览、翻页和打开原文件。其他资源预览模块暂作为独立基础组件保留。

## 已落地的边界

- `MarkdownEditorWidget::document()` 是唯一正文来源，选择、输入法、撤销、保存均通过源码 QTextDocument。
- `editor/markdown/block_parser` 生成可重建的块及源码范围。范围统一使用 UTF-16 代码单元，与 QString / QTextCursor 一致；中文及 Emoji 不需要字节转换。
- `editor/view/markdown_preview_widget` 是统一 QAbstractScrollArea，块不是 QWidget。块使用 QTextDocument 完成 GFM 文字排版；绘制从可见块开始，资源仅在可见时请求。点击块定位源码起点。
- `editor/resources/resource_manager` 分离 URI 解析与后台文件解码。最多两个后台任务，图片降采样，CPU 缓存预算约 64 MiB，以 URI、大小、修改时间为键去重。图片与 CSV 均只读；错误保留路径。每个资源使用固定高度，避免加载完成后滚动跳动。
- `editor/render/renderer_registry` 通过 IResourceRenderer 分派图片和表格绘制，绘制器不做文件 I/O。
- 文件窗口原有 QSaveFile 原子保存、自动保存、格式操作与查找继续使用相同源码。

## 当前范围与限制

本次为 P0 和部分 P1 基础实现，不代表完整路线图完成。

- 支持标题、段落、列表、引用、围栏代码、GFM 表格、独立段落图片和 CSV。CSV 最多读取 51 行、显示前 8 行/列摘要，支持引号、逗号和转义双引号。
- 独立资源支持普通路径、URL 编码路径和 `<含空格路径>`。本地文件限制 32 MiB，图片限制一亿像素，解码目标最多 1600×1200。远程资源明确显示错误，不发网络请求。
- 块识别是基础扫描器，块内语义由 Qt GFM 解析。复杂嵌套、跨块链接定义、完整 CommonMark 源码映射、转义资源语法仍需完善。行内图片显示描述占位，避免绕过异步加载。
- 独立资源预览组件尚未接入原 Live 模式的公式和自定义高亮扩展；应用继续使用原 Live 模式。
- 全文解析做 150 ms 防抖；文字块仍全部排版。只有绘制和资源请求按可见性裁剪，不宣称完成 P2 虚拟布局。
- 尚未实现 DXF、GLB、可扩展 Loader 注册表、任务优先级/取消、外部文件监视、增量解析和稳定 BlockId。资源再次请求时检查文件大小/时间；当前静止视图不会自动监测文件变化。

## 表格编辑基础交互

Markdown 原生表格点击单元格即可在正文中直接编辑；CSV 资源双击打开单元格编辑面板。面板支持行列前后插入、删除、行上下移动、列左右移动。首行为表头，至少保留一行一列。右键可将表格块与前后语义块交换；编辑菜单可插入新 Markdown 表格。

Markdown 表格应用后仅替换对应源码范围，保留列对齐设置；编辑和块移动进入正文撤销历史。CSV 在后台读取完整 UTF-8 文件（最多 8 MiB、10000 行、256 列），应用时用 QSaveFile 保存原 CSV，保留 BOM 与换行类型，正确转义逗号、双引号和多行字段。应用前比较原文件内容；发现外部修改时保留编辑面板并报告冲突。CSV 修改不改变 Markdown 正文，也不进入正文撤销历史。

原生 Markdown 表格在正文中直接编辑，输入、中文输入法、单元格复制/剪切/粘贴、加粗/斜体和行列操作同步回标准 Markdown，支持正文撤销；Tab / Shift+Tab 换格，末格 Tab 自动追加行。CSV 继续使用独立编辑面板。整表保留右键移动，界面不显示整表手柄；原生行列已支持手柄拖拽；更大表格的虚拟化尚未实现。

Markdown 原生表格的右键菜单还提供即时行列操作：在所点单元格的上/下插行、左/右插列、移动当前行列、删除当前行列，至少保留一行一列；列移动同时保留对齐设置。无需先打开编辑面板。CSV 保留原有完整文件编辑面板。

## 行列手柄与边缘追加

原生表格行列手柄默认隐藏，鼠标移到对应行左侧或对应列顶部边缘时才显示；只有移到拖动手柄时切换为手形光标，移开即隐藏。点击可选择整行/整列，拖动到同一表格的其他行列位置可调整顺序，紫色插入线指示落点。列移动同时移动对齐设置，修改可撤销。选择后可复制/剪切整行列，Delete 删除（至少保留一行一列）。鼠标移到表格下边缘时显示追加行的“＋”，移到右边缘显示追加列的“＋”；离开时隐藏。界面不提供整表拖动手柄，CSV 功能继续保留。


## 图片加载与尺寸

图片仅支持 PNG、SVG、JPG、JPEG、BMP、GIF、WebP、TIF、TIFF（扩展名不区分大小写）。其他不支持预览的文件显示单行附件条，显示文件名，点击使用系统默认程序打开。

Live 模式的图片与 PDF、CSV 共用 ResourceManager 的异步加载、缓存和本地资源限制；独立图片通过 RendererRegistry 绘制，行内图片由文档适配层从同一缓存取图。

支持 `![说明|400](图片路径)`，数字表示显示宽度（逻辑像素），高度按图片比例计算。独立图片和行内图片均支持；没有指定宽度时保留原来的自动尺寸行为。尺寸方言保留在 Markdown 源码中，零、负数及非数字不作为尺寸处理。


## 文本资源预览

在独立一行写 `![说明](notes.txt)` 可显示文本资源；同样支持 LOG、JSON/JSONL、XML、YAML、TOML、INI/CFG/CONF、Markdown、TSV 及常见代码文件（HTML/CSS/JS/TS/Python/C/C++/Shell/SQL）。文本按原文显示，不解释 HTML 或 Markdown，也不执行代码。资源与图片、PDF、CSV 共用异步加载和缓存。

支持 UTF-8（含 BOM）以及带 BOM 的 UTF-16/UTF-32；解码失败或含空字符时显示错误。沿用本地文件、32 MiB 上限。预览最多取前 12 行、8000 个 UTF-16 单元，显示区域放不下时省略并提示；Live 模式提供“打开原文件”查看全文。当前为只读摘要预览，不提供资源内部滚动、文本编辑或语法高亮。
