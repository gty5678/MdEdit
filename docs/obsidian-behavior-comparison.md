# Obsidian 行为对照与补齐记录

核对日期：2026-11-07。对象：本仓库 Qt 单文档版 MdEdit。

这是按功能域整理的核心行为清单，不包含全部社区插件行为。状态“已有”表示代码存在相应能力，不表示与 Obsidian 所有边界行为完全相同；“待补”明确表示尚未实现。未测试的行为不能作为验收结论。

## 编辑与阅读

| 行为 | MdEdit 状态 | 差异 / 本次处理 |
|---|---|---|
| 直接输入、中文输入、选区编辑 | 已有 | Qt 编辑控件，复杂输入法组合需交互验收 |
| Live Preview 光标进入显示源码 | 已有 | 按本项目段落/区域边界切换，并非 CodeMirror 实现 |
| 全文源码模式 | 已有 | 保留选区位置与方向 |
| 独立只读阅读模式 | 待补 | 当前只有 Live 与源码两态 |
| 切换模式快捷键 | 部分 | 本项目 Ctrl/Cmd+E 为 Live/源码，Obsidian 还区分阅读视图 |
| 撤销、重做 | 已有 | Live 修改进入同一源文档历史 |
| 自动保存、关闭前保存 | 已有 | 600ms 延时、原子写回，失败阻止关闭 |
| 打开、手动保存 | 本次补齐 | 文件菜单，编辑界面也支持 Ctrl/Cmd+O、S |
| 新建笔记、另存为、重命名、删除 | 待补 | 当前打开现有文件 |
| 加粗、斜体 | 本次补齐 | Ctrl/Cmd+B、I；选区包裹/移除相邻标记；空选区定位标记内 |
| 行内代码 | 本次补齐 | Ctrl/Cmd+Shift+C；简单反引号包裹，内容含反引号时需手工调整 |
| 插入 Markdown 链接 | 本次补齐 | Ctrl/Cmd+K；插入 [选区](url)，url 需自行填写 |
| 删除线、高亮、注释快捷操作 | 待补 | 不将语法输入等同于专用命令 |
| 无选区复制、剪切当前段落 | 本次补齐 | 按源码换行段落操作；末尾有换行时包含换行 |
| 有选区复制、剪切 | 本次统一 | 使用 Markdown 源码范围，跨渲染区域也不丢失标记 |
| 删除当前行 | 本次补齐 | Ctrl/Cmd+Shift+K，无选区时生效 |
| 增加、减少缩进 | 本次补齐 | Ctrl/Cmd+]、[；4 空格；可处理多行，选区末端在下一行起点时不影响下一行 |
| Tab/Shift+Tab 列表层级 | 待补 | 本次仅提供明确的缩进命令 |
| 列表 Enter 续写、空项退出 | 已有 | Live 模式支持无序、有序、任务列表；源码模式未统一 |
| 引用 Enter 续写 | 待补 | 不应误报列表续写已覆盖引用 |
| 任务列表新项默认未完成 | 已有 | Live 模式 |
| 点击复选框、任务状态快捷命令 | 待核验 | 需要独立验收与命令实现 |
| Shift+Enter、代码/公式内换行 | 已有 | 不自动增加列表标记 |
| 括号/引号配对、包裹选区、跳过闭合符 | 待补 | 需保护代码与输入法组合态 |
| 自动补全链接、标签、文件名 | 待补 | 依赖目录索引 |
| 多光标、矩形选区、Vim 模式 | 待补 | Qt 默认单光标 |
| 标题/列表/代码折叠 | 待补 | 现有行号不等于折叠 |
| 字数统计、行列状态 | 待补 | 当前有行号，无完整统计面板 |

## 查找与工作区

| 行为 | MdEdit 状态 | 差异 / 本次处理 |
|---|---|---|
| 当前文件查找 | 本次补齐 | Ctrl/Cmd+F，前后查找、循环、选区预填、大小写选项 |
| 单次替换、全部替换 | 本次补齐 | Ctrl/Cmd+H；按字面文本匹配；单次替换前核对当前选区 |
| 正则、整词匹配、实时匹配高亮 | 待补 | 不宣称与 Obsidian 查找能力完全一致 |
| 跨文件搜索、搜索操作符 | 待补 | 无仓库索引 |
| 文件树、仓库切换、快速切换 | 待补 | 当前单文件架构 |
| 标签页、固定标签、分屏、多窗口 | 待补 | 需引入独立文档会话与保存生命周期 |
| 浏览前进后退、最近文件 | 待补 | 无持久会话记录 |
| 命令面板、自定义快捷键 | 待补 | 本次菜单命令不等于可搜索命令面板 |
| 工作区布局恢复、设置持久化 | 部分 | 基础字号已用 QSettings 持久化；布局恢复待补 |
| 外部文件变化检测、冲突处理 | 待补 | 自动保存不等于磁盘同步；多应用编辑同一文件仍可能覆盖 |
| 文件恢复、版本历史、回收站 | 待补 | 原子保存不等于版本备份 |

## 文档语法、链接与生态

| 行为 | MdEdit 状态 | 差异 / 本次处理 |
|---|---|---|
| 标题、列表、引用、表格、代码 | 已有基础渲染 | Qt Markdown 子集；不能据此声称完全兼容 Obsidian 方言 |
| 代码语言高亮 | 已有部分 | 支持语言见 README，未知语言用等宽字体 |
| 数学公式 | 已有 | MicroTeX 离线排版，与 Obsidian MathJax 兼容范围不同 |
| 相对路径图片 | 已有 | 粘贴/拖入图片自动管理附件待补 |
| HTTP(S) 与页内锚点 | 已有基础 | 仅允许当前已有的明确链接类型 |
| 相对 Markdown 文件链接跳转 | 待补 | 当前点击处理未覆盖本地文件 |
| [[双链]]、别名、标题/块引用 | 待补 | 需链接解析与路径解析器 |
| ![[嵌入]]、块嵌入、PDF/音视频 | 待补 | 需资源类型与递归边界处理 |
| 反向链接、出链、未链接提及 | 待补 | 需仓库级索引 |
| 标签、属性/YAML 属性编辑 | 待补 | 无结构化属性面板 |
| Callouts、脚注、Mermaid | 待补 | 需单独解析/渲染与安全边界 |
| 表格可视化编辑、目录大纲 | 待补 | 当前可直接编辑源码 |
| 图谱、Canvas、Bases | 待补 | 是独立功能域，非编辑快捷键补丁 |
| 日记、模板、书签、随机笔记 | 待补 | 需要仓库与命令体系 |
| PDF 导出、幻灯片 | 待补 | 当前无导出入口 |
| 主题、CSS snippets、自定义字体设置 | 部分 | 设置中可调整基础字号（9–30 pt，默认 14 pt）；字体族、主题与 CSS snippets 待补 |
| 核心/社区插件 API、插件市场 | 待补 | 不具备 Obsidian 插件兼容层 |
| Sync、Publish、移动端、URI 集成 | 待补 | 独立服务/平台范围 |

## 验证与后续实施顺序

本次在现有 smoke 测试中增加 Live/源码两模式的格式切换、选区定位、多行缩进边界、段落剪切与撤销检查。另覆盖查找循环、全部替换与撤销；查找窗口的真实鼠标/键盘交互仍需验收，自动检查不能替代完整交互验收。

后续依赖顺序：统一两模式编辑命令（列表、Tab、配对、任务）→ 阅读模式和完整查找 → 多文档会话/文件生命周期/外部冲突检测 → 仓库索引/双链/搜索 → 工作区和插件能力。上表待补项均未因列入计划而视为完成。
